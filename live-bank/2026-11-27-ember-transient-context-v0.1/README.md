The first narrow candidate for OpenClaw 2026.11.10 build 6ea542f. It owns the existing custom `local` provider only in the profile where it is installed, and opts the exact reasoning-enabled `local/gemma` loopback OpenAI Completions route out of historical runtime-context replay. The rest of its replay policy matches the uploaded compiled runtime. No shared runtime, model weights, session reset, Discord history setting, tools, AGENTS.md or thinking change is intended.

This does not establish live plugin registration, model routing, historical carrier removal, prompt caching or recall. Install disabled first. Confirm the runtime owner, then enable separately in Ember only, following a configuration backup. Do not install in Forge or Forge-mini. If unsupported route/model/config is seen, the plugin deliberately rejects registration or replay rather than silently altering another route; disable if this happens. Do not use on mixed-provider deployments.

Acceptance: retain five recent messages for the initial comparison; verify exact raw model prompts, actual cached/fresh tokens and latency, and room recall.
